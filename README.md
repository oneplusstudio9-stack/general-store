# NandN International — General Store Website

A complete digital general store: 293 products with photos, prices in Rs,
search, filters, sorting, dark mode, column reordering, and an Add to Buy
list. Home, About, Products and Contact sections. Fully responsive.

This is a single static file (`index.html`) — no build step, no database.
Just upload it and it runs.

## 1. Put it on GitHub

1. Go to github.com and click **New repository**.
2. Name it `nandn-international`, leave it Public, click **Create repository**.
3. On the new repo page click **uploading an existing file**.
4. Drag in `index.html`, `vercel.json` and this `README.md`, then click
   **Commit changes**.

## 2. Deploy it on Vercel (free)

1. Go to vercel.com and sign in (use **Continue with GitHub**).
2. Click **Add New → Project**, then **Import** next to `nandn-international`.
3. On the setup screen leave everything as it is — no Framework Preset,
   no Build Command, no Output Directory needed (this is a plain static site).
4. Click **Deploy**. Vercel gives you a live link like
   `https://nandn-international.vercel.app`.

## 3. Updating the site later

Edit `index.html`, or ask for a new version, then upload the new file to the
same GitHub repo. Vercel redeploys automatically on every push.

## Notes

- Prices are in Pakistani Rupees (Rs), as listed on 8 Oct 2026.
- The site works offline too: just open `index.html` in any browser.
